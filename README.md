## 🎭 À Propos · 关于本剧

<div align="center">

| | |
|:---:|:---:|
| 🎼 **作曲 / 作词** | **Félix Gray** |
| 🎬 **首演** | 2005 年 · 巴黎 |
| 📍 **故事地点** | 塞维利亚 · Sevilla |
| 🎭 **类型** | 法语音乐剧 · Comédie Musicale |

</div>

<br>

这是一部被严重低估的法语音乐剧瑰宝。Félix Gray 将西班牙弗拉明戈的热烈与法国香颂的深情熔于一炉，在塞维利亚的月光下铺开一幅关于**欲望、背叛、救赎与毁灭**的画卷。

唐璜这个被反复演绎的传说人物，在这里不再是一个单纯的浪荡子符号。他有血有肉，有挣扎，有恐惧，有一颗逐渐裂开的石之心。

> *« Car Don Juan ne connaissait ni amour, ni pitié, ni regret, ni respect. »*
>
> *"因为唐璜既不懂爱情，又无怜悯之心，既无悔恨之意，又无尊重之心。"*

## 🕯️ Post-scriptum · 后记

> 法语音乐剧有一种独特的气质：它不讲道理，它不讲道德。
> 它只负责把美的、痛的、燃烧的一切摊开在你面前。
>
> 唐璜不是英雄，也不是恶棍。
> 他是一个把所有路都走绝了的人。
> 而当爱终于降临在他身上时，他已经没有路了。
>
> 这就是悲剧。
>
> *« Il était une fois à Séville... »*
> *"故事就发生在塞维利亚……"*
